# Data-Drift-Data-Decay-PowerBI-Dashboard
📊 Data Drift & Data Decay Analysis Dashboard
📌 Project Overview

This Power BI project focuses on identifying, monitoring, and analyzing Data Drift and Data Decay in datasets over time. The dashboard helps stakeholders detect changes in data distribution, performance degradation, and potential risks affecting model accuracy or business decisions.

The goal is to ensure data reliability, maintain model performance, and support proactive decision-making.

🎯 Objectives

Detect Data Drift (changes in feature distribution over time)

Identify Data Decay (gradual reduction in data quality or model performance)

Monitor key statistical metrics

Provide visual insights for business and data teams

Enable early intervention before performance degradation impacts outcomes

🧠 Key Concepts
🔹 Data Drift

Data Drift occurs when the statistical properties of input data change over time compared to the training dataset.

Types of Drift Covered:

Feature Distribution Drift

Target Drift

Concept Drift

🔹 Data Decay

Data Decay refers to:

Declining data freshness

Increasing missing/null values

Reduced data quality

Decreasing model performance over time
